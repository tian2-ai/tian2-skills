# 丘奖提交材料审查清单（2026 内地赛区，12 项）

口径：模拟组委会 9/16–9/30 材料审核。判定只用 `pass` / `revise` / `blocked`；
★ = 取消资格级，任何一项 `blocked` 则整体 `blocked`。核实日期 2026-08-31；
2026-09-09 对 RULE（page-rule.html）与 AI（show-86-59.html）在线复核，无变化。
来源缩写：RULE = page-rule.html；NOTICE = show-86-58.html；AI = show-86-59.html；
FAQ = page-assessment.html；CRIT = page-criteria.html。

---

### 1. ★ 报名信息与团队资格

- **判定标准**：1–3 名学生来自**同一中学**，内地赛区均为高中生；指导老师 1–2 人；导师不来自
  公司或培训机构；同一论文只报一个学科（报多科须另注册账号、用不同论文）；报名系统信息与
  报告封页、诚信声明、导师信息表三处的人名/单位完全一致。
- **整改动作**：跨校或超员 → 9/15 前重组团队；机构导师/实际机构指导 → 如实核查指导来源并咨询组委会；更换署名不能消除既往事实；
  三处信息不一致 → 逐项对齐。提醒：报告提交截止后团队与导师信息不可再改。
- **来源**：RULE 四（一）（二）；FAQ。

### 2. 研究报告 PDF 与结构

- **判定标准**：电子版 PDF（书面提交无效；扫描图片版查重系统无法处理）；封面页含
  **姓名、省份/州、国别、指导老师姓名、报告标题**；第二页起依次为题目、作者、摘要、关键词、
  目录、正文；参考文献另起一页；有致谢页。语言中英不限（总决赛须英文）。
- **整改动作**：跑 `scripts/check_report_pdf.py`；缺字段补封页，顺序错乱按官方顺序重排，
  非 PDF 重新导出。
- **来源**：RULE 四（四）；官方报告模板（2025-04-14 版）。

### 3. ★ 致谢页三要件 + 字数

- **判定标准**：覆盖官方三段"致谢页中，必须……"的全部要素：①研究背景与选题来源、**每位队员
  从选题/数据获取/分析计算/实验设计实施/撰写的逐环节分工**、**不同环节遇到的困难及解决问题
  的经过**（规则页明列要素，不可缺）；②指导老师与学生的关系、写作中所起作用、**指导是否有偿**；
  ③他人协助完成的成果（如有必要可附学生与导师简历，官方允许项）；④AI 使用情况——工具名称及
  版本、具体使用环节及用途、使用时间及频率（未使用时建议如实写明，属审查建议）。**字数口径**：
  规则页"此部分要求 1-2 页 word 文档（500-1500 字）"紧随 AI 段之后，指 **AI 使用说明部分**；
  致谢页其余部分无字数上限。模板旧版（2025-04-14）写 500–1000 且无 AI 条款，以规则页为准。
  可参照 `../assets/templates/致谢页模板.md`（含六科 AI 注意事项与"推导协助三情形"表述）。
- **整改动作**：缺哪件由学生本人补写；"共同完成"式套话要求逐人逐环节重写；有偿与否写成明确
  判断句。审查者给要素清单，不给成品段落。
- **来源**：RULE 四（四）d；NOTICE；AI。

### 4. ★ 学术诚信声明（2026-07-08 更新版）

- **判定标准**：使用更新版模板；**学生签字 + 学校负责人签字 + 学校或教务处公章**；**每位指导
  老师签字 + 所在单位负责人签字 + 单位公章**（非本校导师盖其所在单位章）；全队一份，扫描为
  PDF 上传。
- **整改动作**：旧版模板或缺任一签章 → 重办；盖章有行政周期，倒排至少 7 天。
- **来源**：RULE 四（五）；模板 02_学术诚信声明_更新。

### 5. 指导老师信息表

- **判定标准**：1–2 位导师**分别**填写各自一份（docx 模板），签名 + 单位公章，扫描 PDF 上传；
  单位信息与诚信声明、致谢页一致。
- **整改动作**：两位导师只交一份 → 补第二份；未盖章 → 补盖。
- **来源**：RULE 四（五）；模板 03_指导老师信息表.docx。

### 6. ★ 查重报告 ≤10% 且对应最终版

- **判定标准**：上传最终版论文后、9/15 前上传**与最终版对应**的查重报告（官方推荐知网、
  PaperPass 等，无封闭名单）；重复率 ≤10%。超过 10% 取消该团队资格；全篇抄袭/代写连带
  取消该校全部队伍并通报。
- **整改动作**：哈希一致为辅助证据；不同先核版本/内容，实质内容改动 → 用最终版重出；超标 → 学生自行规范引注、
  用自己的话重写后重查（不提供"降重技巧"）。
- **来源**：RULE 四（四）（六）。

### 7. ★ AI 使用披露 + 聊天记录（"其他材料"栏）

- **判定标准**：AI 用法落在允许清单（润色/语法/代码调试/文献检索线索/结构梳理/图表草稿/
  数据分析辅助），无禁止行为（代写论文主体/虚假文献/伪造数据/未声明使用/上传涉密、敏感或未授权数据）；使用**事先获
  指导教师许可**；致谢页名称及版本、环节及用途、使用时间及频率齐备；已人工核验文献真实性、引用原意、公式/代码/结果、版权与数据安全；**相关AI聊天记录必交，其他辅助材料如有一并上传至报名系统
  "其他材料"栏**，且与披露环节一一对应。
- **整改动作**：缺披露 → 学生补写（写法见 /yau-ai-compliance）；缺记录 → 立即导出现存记录，
  缺失时段如实说明；发现禁止行为 → `blocked`，相应内容由学生重做并如实披露。
- **来源**：AI（2026-07-08）；RULE 四（四）。

### 8. ★ 伦理审查批准 + 知情同意书（如适用）

- **判定标准**：研究不涉及对人体/动物有生理心理危害的食品、烟酒、药品、医疗器械类（此范围
  直接不合规）；涉及以人为对象的生命科学与医学研究、动物实验、或可能触及生物伦理边界的，
  已上传**伦理审查委员会书面批准（签字盖章）**和**研究对象签署的知情同意书**。
- **整改动作**：禁止范围 → `blocked`，调整研究范围；需批文未取得 → 停止相关数据采集先补
  审查，事后补批须如实说明批文日期。
- **来源**：RULE 四（三）（五）；NOTICE。

### 9. 机构/实验室许可（如适用）

- **判定标准**：依托专业研究机构或实验室完成的研究，已上传该机构**签字盖章的许可**，注明
  学生参与科研项目的名称、时间、成果用途、指导人员。
- **整改动作**：缺许可 → 联系机构出具；许可上的项目名称/时间须与报告正文一致。
- **来源**：RULE 四（五）。

### 10. ★ 一稿多投申报

- **判定标准**：报告若曾参加、正在报名或有意愿参加其他竞赛，或已发表/拟投稿，已在系统
  "提交研究报告页面"如实填写。
- **整改动作**：漏报 → 截止前补填；拿不准是否算（校内评比、预印本）→ 从宽申报或书面咨询组委会。
- **来源**：RULE 四（四）。

### 11. 引注规范与真实性材料

- **判定标准**：引用他人方法与结论均有引注并入参考文献；无 AI 生成的虚假引文（逐条可溯源）；
  可选材料（实验视频、算法、可执行程序、源代码、图文资料）与正文一致——计算机奖评审标准
  明确"建议提交视频、可执行程序包、源代码等证明真实性"，化学奖要求他人帮助（如大型仪器）
  注明姓名与内容。
- **整改动作**：查不到原文的引文删除或替换；可选材料与正文冲突以数据为准。
- **来源**：RULE；AI；CRIT。

### 12. 提交动作与留痕

- **判定标准**：全部材料在 9/15 24:00 前经报名系统在线提交（书面无效）；最终版上传后不再改动
  查重对应的文件；提交成功页面截图留存；入围后报告将网上公示，学生知情。
- **整改动作**：给出倒排时间表（盖章类 D-7、查重 D-3、提交 D-1 留缓冲）。
- **来源**：RULE；FAQ Q9；show-86-57 日程。

## 使用规则

1. 每项写：判定 / 证据位置 / 整改动作 / 谁做 / 最晚何时。
2. 先 ★ 项后非 ★ 项；缺证据判不了的项标 `revise` 并写明所缺证据。
3. 整改全部指向学生或学校经办人，审查者不代办。
4. 与当季官网公告冲突以官网为准，冲突条目写入报告"依据与待核实"。
