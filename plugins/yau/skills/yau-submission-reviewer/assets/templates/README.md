# 丘成桐中学科学奖研究报告模板包（2026 内地赛区）

官方只发了一份 4 页的结构示意模板（从 https://www.yau-awards.com/lists-download.html 下载《研究报告模板》，2025-04-14 版；维护者本地归档不随 skill 分发）：
P1 封面页 → P2 题目/作者/摘要/关键词/目录/正文 → 另页参考文献 → 致谢页。
**官方模板为纲，本模板包在其骨架上做细化**——补齐章节骨架（六科评审标准的报告八要素）、
致谢页四要件占位、以及每个占位处的官方要求出处。官方模板与本包冲突时，以官方为准。

核实日期：2026-09-09（规则依据核实于 2026-08-31 抓取的 yau-awards.com 快照 +
2026-09-09 复核）。

## 文件清单

| 文件 | 是什么 | 怎么用 |
|---|---|---|
| `yau-report-template.tex` | 完整 LaTeX 模板（xeCJK，Songti SC / PingFang SC） | `xelatex` 编译两遍出目录；〈尖括号〉占位整体替换；注释里写了每项要求的官方出处 |
| `yau-report-template.pdf` | 上述模板编译出的示意 PDF（7 页） | 看排版效果用，不是提交件 |
| `yau-report-template.docx` | 同结构 Word 版（标题/正文/图表题注样式 + 封面字段表） | 直接在 Word 里替换占位；目录用"引用 → 目录"插入；灰色段落是说明文字，完稿前删除 |
| `致谢页模板.md` / `.docx` | 致谢页 + AI 使用说明**主模板（骨架）**：全要素占位、AI 环节表、三选一表述块、分学科注意事项 | 〈占位〉整体替换、按学科保留对应块；这是"从零写致谢页"的起点 |
| `致谢页范例.md` / `.docx` | 一篇约 750 字的**完整合成范例**（虚构的两人传感器课题） | 学写法，不抄内容——顶部红字警示：人名与事实均为虚构，照抄视同不实陈述 |
| `范例论文-结构解读.md` | 2024 物理银奖《拉不开的"纸钳子"》逐节结构解读 | 看一篇真实获奖论文每节写什么、篇幅比例、可模仿与要避免的点 |

**模板与范例的关系**：《致谢页模板》是待填写的骨架——占位保留、按你的事实替换；
《致谢页范例》是一份已填写完成的示范成品——只用来对照"填完应该长什么样"。
先照模板逐项填，再对照范例检查写法是否具体、可核验。

## 致谢页字数口径：500–1500 字指 AI 使用说明部分

规则页（page-rule.html）原文"此部分要求 1-2 页 word 文档（500-1500 字）"**紧随
AI 使用情况段之后，指 AI 使用说明部分**；致谢页整体没有字数上限，但各要素须
"详细说明"。官方报告模板旧版（2025-04-14）写 500–1000 字且无 AI 条款，以规则页为准。
必备要素缺一不可：①研究背景与选题来源 ②逐环节逐人分工 ③**不同环节遇到的困难及
解决问题的经过** ④导师关系、作用与是否有偿 ⑤他人协助（注明姓名与内容，如有必要
可附学生与导师简历）⑥AI 披露：工具名称及版本、使用环节及用途、使用时间及频率
（show-86-59.html，2026-07-08；未使用也写明"未使用"），此部分 1–2 页（500–1500 字）。
