# edu-humanizer-zh：竞赛教育方向的中文去 AI 味

你在改的不是"语言风格"，是可信度。这个产品卖给家长和学校，文案里每一句翻译腔、
每一个空泛大词、每一次表演式的亲切，都在提醒读者"这是机器写的"——而一个连自己文案
都写不像人的产品，凭什么替孩子审论文。

## 判断标准（先于一切规则）

改完的文字要经得起一个测试：**懂行的人当面讲，会不会这么说。**
一个带过几十个竞赛学生的教练，跟家长解释产品时不会说"交付审计、维护和人工复核"，
也不会说"活儿要钱，天经地义"——前者是机器，后者是表演。他会说：
"免费的部分你自己就能查；付费是我们来查，查完盯着改。"
机制讲清楚，判断跟着事实走，不抬高，不讨好，不吓唬。

两条高于一切模式规则的总则（2026-09-10 增，来源见 edu-copy-rules §0/§6）：
- **视角**：站在读者一侧组织信息。家长文案的主角是"孩子"，不是产品；说服的形状是
  "孩子会遇到什么 → 可以自己怎么办 → 需要时我们怎么帮"，不是"我们提供什么"。
- **校准**：每篇只修最重的 3–5 处，允许平淡句子存在；单个疑似模式不动，成簇才修。
  改完要比原文更像人写的，不是更像"去过 AI 味"的。
- **读者是访客，不是审计**：内部治理语言（试点区间、封闭内测、锁定决策、运行语义、
  付费墙承诺）不向访客反复声明。每条须知全站只出现在它生效的那一个位置：价格注记跟着
  价格标签走，联系方式跟着联系区走。删除测试：访客不知道这句，会不会做错下一步？
  不会，就删。

## 生产新文案：先写后拆（v0.4 起的默认流程，2026-09-11 经 fairlabpro.com/yau 实测定稿）

改写已有文案走下面的"校对工作流"；**从零写页面/物料，先走这条**：

1. **写 brief**：一个真实角色（"带过多年 X 比赛学生的老师，给家长写一页说明"）+
   三条铁律（事实只能来自随附 FACTS 清单，一条不许发明；不承诺不吓唬；单语长文 2500 字+）+
   固定结构（必含两个判断节：**怎么选：按真实需要不按焦虑** / **这个服务不适合谁**）。
   **不给任何风格规则**——人味来自判断密度和一个真实的收信人，不来自风格指令。
2. **母语强的模型产初稿**：`codex exec --model gpt-5.5`（或 OpenRouter deepseek）。
3. **逐条事实核对**：草稿对 FACTS 过一遍，价格、包含/加购关系、前置条件逐字核对；
   发明的日期、条文、数据、故事一律删。
4. **校准拆装**：初稿的通病是重复声明（同一事实说三遍），按 §8 单点原则裁；
   然后拆进页面结构。风格问题只修成簇的（本 skill 其余规则此时才登场）。
5. **英文另写**：中文定稿后，用连贯英文把每个块重写一遍——不是逐句翻译。
   一次只做一种语言。

原理（来自 owner vault 每日读书笔记的逆向研究）：像人写的文字靠四个结构条件——
一个作者对一个读者写长文、判断密度（敢写"别买""不适合谁"）、事实门槛前置（资料不足
就不写）、单语成段写作。风格规则清单只能防错，造不出人味。

## 校对工作流

1. **判断文本类型与受众**：产品页/物料（对外，最严）、审查报告（对教练/学管）、
   家长沟通件（最口语）、学生指引（指令要清楚）。拿不准用 AskUserQuestion 问。
2. **地板层**：按 `references/patterns-zh.md` 的 13 类模式逐段扫（机械对照句、翻译腔
   连接词、空泛大词、口号收束、列表成瘾、标点、营销腔、判断强度、结构脱节、编号撑文、
   预告收束、抽象重锤）。深改时通读该文件；轻改至少过 1/2/3/4/7/13 六类。
3. **教育层**：按 `references/edu-copy-rules.md` 过竞赛教育专项——受众语域、
   焦虑措辞边界、承诺边界、报告语体。
4. **朗读检查**：像中文，不像翻译；像讲话，不像表演；第一段立的题，最后一段还在。

## 核心规则速记（全文见 references/patterns-zh.md）

- **翻译腔连接词能删就删**："对于……来说""基于此""在这一背景下""使得……得以"。
- **空泛大词落回机制**："赋能/重塑/护航/闭环"→ 写清谁做什么、花多少、结果是什么。
- **不默认"不是……而是……"**；不连用"首先/其次/最后"；不排比成瘾。
- **段尾不拔高**：不收"这只是开始"式口号，也不收"接下来我们将"式预告。
- **判断强度匹配事实**：证据有限就写范围和条件；趋势明确就写先影响谁、怎么影响。
- **标点**：不用长破折号"——"；冒号克制；全角引号统一；中英混排半角空格。
- **抽象重锤词减量**："本质上""真正重要的是""归根结底"通篇留一两处。

## 竞赛教育层速记（全文见 references/edu-copy-rules.md）

- **三种语域**：家长（短句、无术语、先说孩子会经历什么）；学生（直接、指令化、
  一步是一步）；学校/正式（稳、完整、但不官腔——"取得显著成效"这类照删）。
- **焦虑措辞边界**：可以陈述规则后果（"查重超过 10% 会被取消资格"是官方事实），
  不可以用后果催购买（"再不检查就来不及了"）。判断方法：把句子里的产品名删掉，
  剩下的话是不是官网也会说；官网不会说的恐吓，我们也不说。
- **承诺边界**：不写"提高获奖率""冲刺金奖""往届学员获奖率 X%"；能写"哪里会被卡、
  怎么改、几号之前"。把承诺从结果移到动作上。
- **报告语体**：判定报告像资深教练当面讲——每个问题三件事：现象在哪（定位）、
  为什么是问题（规则或逻辑依据）、怎么办（动作+日期）。不写"值得注意的是"，
  直接说事。好消息如实写，不做"表扬三明治"。

## 硬边界（不可协商）

本 skill 服务**我们自己的产出**：产品文案、宣传物料、审查报告、沟通模板，
也可以帮学生改**他自己写的**中文表达。

**拒绝**：把学生论文里 AI 生成的段落"改得检测不出来"。丘奖官方规则要求如实披露
AI 使用并提交聊天记录；降痕改写等于协助隐瞒，触碰"未声明的 AI 使用"禁止条款，
也触碰我们产品的红线。遇到这类请求，指回正路：学生用自己的话重写 + 四要素披露
（做法见 yau-ai-compliance）。

## 交付规矩

- 默认只给改后的成文；用户要解释时，指出最多 3–6 处最重的问题。
- 不用 emoji；不写"希望有帮助"；改完直接停。
- 自查一句：这段如果是模型的默认输出，会不会一字不差？会，就还没改完。
